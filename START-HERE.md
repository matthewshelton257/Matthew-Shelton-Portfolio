### 2. A working workflow with evidence you can inspect

**Customer Voice → Campaign Brief** turns review text and product facts into a messaging brief. It retains source quotes, keeps unmet needs visible and prevents unsupported feature requests from becoming template promises.

Built with AI assistance. The free default uses deterministic rules and templates on synthetic data. An optional local-model adapter is included, with live inference still unverified. The repository contains runnable code, example outputs and automated checks.

**[Read the sample brief](https://github.com/matthewshelton257/customer-voice-to-campaign/blob/main/examples/brief.md)** · **[Inspect the implementation](https://github.com/matthewshelton257/customer-voice-to-campaign)**

### 3. Lifecycle strategy tied to meaningful behavior

The independent **Ray** proposal connects first-session activation with repeat use and re-engagement. It includes email mockups, event-based eligibility, suppressions, holdouts and outcome definitions. The intended measurement is completed workouts, not email opens alone.

This is an uncommissioned strategy project based on public information. It has not been deployed and has no measured campaign results.
