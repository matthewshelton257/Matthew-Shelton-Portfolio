# AI tool-testing journal

This journal is intentionally unfilled. No new-tool benchmark or hands-on comparison has been completed in this repository. Add entries after actually using a tool. Release announcements alone are research notes, not test results.

## Suggested comparison tracks

Structured output reliability, source-grounded drafting, prompt-injection resistance, local model feasibility and workflow-tool integration. Test a narrow question each time rather than chasing every release. No tools are ranked or endorsed here.
