# Campaign copy and design

These project samples show the message in context: who it is for, the action it asks for and how it would fit into a journey. They are independent concepts; project pages include status and AI contributions.

## Pango · Start a relevant conversation

The prospecting sequence uses a specific observation from a brand’s published policy to ask about its workflow. The three examples cover Thursday Boot Company, Mizzen+Main and Marine Layer.

[Read the outreach sequence](../case-studies/pango/campaign-playbook.md) · [View the landing page and emails](https://www.figma.com/design/BxZFyUx1DTxEwEXugZwpEe?node-id=2-2)

## Illume · Make the next action clear

An introduction to Taro, an example question and chart-status messages address questions raised during a product walkthrough.

[Read the copy pack](../case-studies/illume/message-and-interface-copy.md) · [View the email and landing-page designs](https://www.figma.com/design/Rhk6OdhcG6vIbMKSTIRBio?node-id=4-136)

## Ray · Start and return

> Welcome to Ray. Tell us what you have to work with today. We’ll take it from there.
