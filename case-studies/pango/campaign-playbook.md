## Reply handling

| Reply | Action |
| --- | --- |
| Interested | Ask which workflow matters and who owns it; route to Steve with source, message and reply context |
| Uses another tool | Acknowledge it; ask whether a relevant coordination gap exists, without promising replacement or integration |
| Wrong person | Request a pointer once; do not count this as qualified interest |
| Not now | Ask whether a specific future month is appropriate; otherwise close |
| No interest / opt-out | Stop and record suppression |
| Technical question | Send to Steve; do not invent capabilities |
| Out of office | Record return date; do not count as a human reply |
